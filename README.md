# 💜 Maddy AI – 3D Voice Calculator

## 🚀 About the Project

Maddy AI is an interactive voice-enabled calculator developed using Python, Flask, HTML, CSS, and JavaScript.

It allows users to perform mathematical calculations using buttons or voice commands and hear the results.

## ✨ Features

- Modern futuristic animated UI
- Interactive robot-style assistant
- Basic mathematical operations
- Voice input through microphone
- Browser-based speech recognition
- Spoken calculation results
- Responsive user interface

## 🛠️ Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- Web Speech API

## ⚙️ Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/madhuri3-cmd/Maddy-AI-Voice-Calculator.git
```

**2. Open the project folder**

```bash
cd Maddy-AI-Voice-Calculator
```

**3. Create a virtual environment**

```bash
python -m venv venv
```

**4. Activate the environment (Windows)**

```powershell
venv\Scripts\activate
```

**5. Install Flask**

```bash
pip install flask
```

**6. Run the application**

```bash
python app.py
```

**7. Open in your browser**

http://127.0.0.1:5000/

## 🎤 How to Use

1. Open the application in Google Chrome.
2. Use calculator buttons to perform calculations.
3. Click the microphone button to give a voice command.
4. Allow microphone permission.
5. Listen to the calculation result.
